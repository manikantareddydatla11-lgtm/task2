Random Quote Generator

Project Description

A Random Quote Generator is a web application that displays a random inspirational quote along with its author's name whenever the user clicks the button.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Displays 15 inspirational quotes.
- Shows quote and author name.
- Generates a random quote on button click.
- Prevents the same quote from appearing twice consecutively.
- Includes a share button.
- Responsive design for mobile and desktop.

How to Run

1. Create a file named "index.html".
2. Copy the complete code into the file.
3. Save the file.
4. Open it in your browser.

Learning Outcomes

This project demonstrates JavaScript arrays, objects, random numbers, event handling, DOM manipulation, and the Web Share API.
